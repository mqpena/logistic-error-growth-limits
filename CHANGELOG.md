# Changes

## 1.0.0

- Link the published SQG dataset, DOI `10.5281/zenodo.22822514`, and distinguish
  its identifier from any future software DOI.
- Apply MIT to original code and CC BY 4.0 to original scientific data,
  figures, results and documentation.
- Add the portable September 2026 existing-data audit and its original
  specifications, mathematical checks and explicit numerical limitations.
- Align the CPU requirements with the validated Python 3.13 environment;
  separate optional MLX dependencies.
- Run both unittest-style and function-style regression tests through one
  entrypoint, including optional raw-data provenance checks.
- Preserve the original compact evidence, preprint figure sources and
  scientific thresholds. No new model integration or statistical sampling
  is part of this release.
